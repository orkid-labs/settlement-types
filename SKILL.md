# settlement-types

settlement-types defines the wire format for Orkid settlement intents: chain-agnostic order descriptions, settlement targets (EVM and Hedera), and status enums shared between solvers and clients.

## When to use

Integrating with Orkid settlement flows or building cross-chain intent systems in TypeScript.

## Install

```
npm install @orkid-labs/settlement-types
```
